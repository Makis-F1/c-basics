## PROJECT 

-Calculator that can do the 4 simple operations(+,-,*,/)

One of the important thing for this is a do while command. With that command we make sure the user can use the calculator as many times as he wants to until he decides to exit. So after using do while we ask the user to choose what does he want to do +,-,* ,/ and we give him an option to exit so he can exit when he is done with everything. When he chooses an operation and after that the two numbers then comes our switch case. Swtich case allows us to have a cleaner code when choices like this are in question. For / we added an if which checks if the second number is 0, if it is it sais "You can not divide with a zero". And in the end default gives us "Invalid operation" which means nothing from the options was choosen so chose again.
