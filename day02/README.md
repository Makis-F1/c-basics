## Day 2

Day 2 is about some basic math

## Tasks

-1. Task was to make a program that sums up two numbers that a person types in

I used scanf to let the user enter two numbers, than just sum up those two numbers nothing really that hard

-2. Task was to calculate the perimeter and volume of a circle

For the number PI I used 3.14. I let user chose a radius than calculate perimeter by this formula: 2r*PI (3.14) , and volume by this one:r^2*PI.
Than just printf the results.

-3. Task was to calculate the average speed from distance travelled and time it took

Another scanf to get the distance and time. You divide distance by time(s/(s/t) and get the result.

-4. Task was to make a mini conversion program that converts km/h to m/s

Only new thing I had to know for this was to divide the number in km/h with 3.6 to get m/s.
